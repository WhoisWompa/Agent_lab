# Topic - strategic play among LLM agents

LLM agents in games with hidden information, hidden roles, or opposed or partly aligned goals: negotiation and bargaining, social deduction, cheap talk between agents, and the trust, deception and coordination that emerge in play. The subject is how the agents play and what the communication channel does, not a shared-task team.

## Papers (20)
- [[2023-05 Improving Language Model Negotiation with Self-Play and In-Context Learning from AI Feedback]] — Two LLMs bargain as buyer and seller while a third LLM critic writes advice that is fed back as in-context demonstrations, to test whether models can improve each other without human input. (also: [[Topic - self-refinement and critique loops]])
- [[2023-09 Cooperation, Competition, and Maliciousness]] — A scorable six-party, five-issue negotiation game that measures how well LLM agents cooperate, compete and resist a greedy or sabotaging teammate. (also: [[Topic - agent evaluation benchmarks]], [[Topic - reasoning prompting]])
- [[2023-09 Exploring Large Language Models for Communication Games]] — Seven frozen gpt-3.5 agents play the social-deduction game Werewolf, using retrieved history, self-reflection and a pool of past-game experience instead of fine-tuning.
- [[2023-10 Avalon's Game of Thoughts]] — ReCon is a prompting scheme (private thinking, then a second pass that checks how others will read the draft speech) that helps LLM agents play the hidden-role game Avalon without being deceived or leaking their own role. (also: [[Topic - self-refinement and critique loops]], [[Topic - reasoning prompting]])
- [[2024-02 How Well Can LLMs Negotiate]] — An open-source platform of three two-player negotiation games is used to rank four LLMs against each other and to show that persona prompts raise payoffs while anchoring and other irrational habits leave the agents exploitable. (also: [[Topic - agent evaluation benchmarks]])
- [[2024-02 Large Language Model based Multi-Agents]] — A survey that organises LLM-based multi-agent work along four axes (environment interface, agent profiling, communication, capability acquisition) and two application streams (problem solving, world simulation), then lists open challenges. (also: [[Topic - role-based agent teams]], [[Topic - multi-agent debate and consensus]])
- [[2024-02 Secret Collusion among AI Agents]] — Formalises secret collusion, where LLM agents hide their coordination from an overseer by steganography, and measures how well current models can do it and how well proposed defences hold. (also: [[Topic - team theory and distributed decision making]])
- [[2024-07 Richelieu]] — A single LLM agent for the seven-player game Diplomacy that models others' intentions, plans sub-goals, checks whether negotiating partners are lying, and improves by storing self-play experience in memory, with no human game data. (also: [[Topic - self-refinement and critique loops]])
- [[2025-02 Multi-Agent Risks from Advanced AI]] — A taxonomy of the risks that appear only when many advanced AI agents interact: three failure modes, seven risk factors, thirteen illustrative case studies and research directions for each. (also: [[Topic - communication topology and channels]], [[Topic - team theory and distributed decision making]], [[Topic - agent system failure analysis]])
- [[2025-10 Communication Enables Cooperation in LLM Agents]] — Compares two ways of getting LLM agents to cooperate in social dilemmas, a one-word cheap-talk channel (works almost perfectly) and an in-context curriculum of games (makes agents worse).
- [[2025-11 Echoing]] — Names and measures "echoing", where an LLM agent in a two-agent negotiation drops its assigned role and starts speaking as its counterpart, and shows prompts, reasoning and a structured-output protocol only reduce it. (also: [[Topic - role-based agent teams]], [[Topic - agent system failure analysis]])
- [[2026-01 Lying with Truths]] — A Writer-Editor-Director team of attacker agents picks and orders only true evidence fragments so that victim LLM agents infer a false conclusion on their own, and downstream judges then ratify it. (also: [[Topic - role-based agent teams]], [[Topic - communication topology and channels]])
- [[2026-02 Colosseum]] — Measures whether a subset of LLM agents in a cooperative team pursues a hidden side goal, by pairing a regret metric on actions with an LLM judge on messages, and finds that giving benign agents a secret channel is enough to trigger it. (also: [[Topic - team theory and distributed decision making]], [[Topic - communication topology and channels]])
- [[2026-02 Communication Enhances LLMs' Stability in Strategic Thinking]] — Letting small LLM agents exchange one free sentence of costless, non-binding "cheap talk" before each move in a repeated Prisoner's Dilemma makes their cooperation trajectories smoother and more predictable, though not necessarily more cooperative. (also: [[Topic - communication topology and channels]])
- [[2026-02 MERIT Feedback Elicits Better Bargaining in LLM Negotiators]] — Builds a nine-market buyer-seller bargaining benchmark (AgoraBench), a human-preference-fitted score for buyers (MERIT), and shows that giving that score to an LLM buyer as a private reward in the prompt, or fine-tuning on human-preferred dialogues, improves bargaining. (also: [[Topic - agent evaluation benchmarks]], [[Topic - preference learning]])
- [[2026-02 PieArena]] — A negotiation benchmark built from MBA-course scenarios that ranks 13 LLM agents by head-to-head play, anchors them against trained human negotiators, and profiles behaviour (lying, arithmetic, rule compliance) beyond the deal outcome. (also: [[Topic - agent evaluation benchmarks]])
- [[2026-04 Detecting Multi-Agent Collusion Through Multi-Agent Interpretability]] — Frames collusion detection as a composite hypothesis test over per-agent activation probes (HELIOS) and tests it on a new benchmark, NarcBench, where probes catch collusion that transcript monitors miss but transfer poorly to emergent collusion. (also: [[Topic - agent evaluation benchmarks]])
- [[2026-06 Byzantine Cheap Talk]] — Shows that the cooperation which one-word cheap talk buys LLM agents in a 4-player Stag Hunt breaks under a single lying agent and under announced visibility limits, and that models split into two stable response types. (also: [[Topic - communication topology and channels]])
- [[2026-07 Moral Hazard in Multi-Agent Language Models]] — A text game built on Holmström's moral hazard in teams shows that LLM agents differ in whether they pay to help a teammate, that optimisation can reach full team success while skipping the costly help, and a counterfactual prompt optimiser (CREDIT) that rewards the help itself. (also: [[Topic - contract theory]], [[Topic - automated pipeline and topology search]])
- [[2026-09 Cheap Talk Stabilizes Strategic Interaction in LLM Agents]] — One sentence of non-binding pre-play messages cuts round-to-round action flipping of 7-9B LLM agents in repeated 2x2 games from 63.8% to 18.9%, and probes show the effect depends on model, framing and the partner's last move.
