# Topic - presentation sensitivity

Decisions that change with option order, option names or labels, the set of listed options, question form or request serialisation, though the content is logically the same; and methods that remove the sensitivity.

Group: Mechanisms. See [[Topics]]. Same group: [[Topic - confidence-gated escalation]], [[Topic - calibration]], [[Topic - abstention and fallback]], [[Topic - adaptive reasoning depth]], [[Topic - reasoning prompting]].

## Papers (2)
- [[2026-06 The Self-Correction Illusion]] — Moving a wrong claim, unchanged, from the agent's own `<thought>` into a user, tool or system-memory message makes models explicitly flag it far more often, so the self-correction gap is largely a chat-template role artifact, not a reasoning deficit. (also: [[Topic - self-refinement and critique loops]])
- [[2026-08 Does a Tool Result Carry More Authority Than Plain Text]] — Three preregistered studies on one model ask whether an unsupported claim is adopted more often when it arrives as a native tool result than as plain text, and find the apparent tool-result advantage disappears once the text comparator is made active. (also: [[Topic - judge and decision-model audits]], [[Topic - abstention and fallback]])
