# Topic - automated pipeline and topology search

Searching for or learning the prompts, demonstrations, workflow, agent roles or communication graph of an LM pipeline or multi-agent system against a metric, instead of hand-writing them: compiled prompt programs, bootstrapped demonstrations, workflow search, learned or pruned agent topologies. The subject is the optimizer and what it finds, not the wording of any one prompt.

Group: Agent systems. See [[Topics]].
