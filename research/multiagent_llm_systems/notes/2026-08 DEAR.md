# Group Perspective Matters: Regulating Debate Relationships Can Mitigate Blind Conformity in Multi-Agent Debate

## One line
DEAR trains two small reinforcement-learning agents that decide, after each debate round, which peers each LLM may read and how randomly it samples, using the agreement between answers as the signal, to curb blind conformity and save tokens.

## Method
Problem: in multi-agent debate the minority drops its own reasoning to follow the majority (blind conformity). Earlier fixes filter peer answers by each model's confidence or perplexity. The authors argue both are unreliable: LLMs are overconfident, and perplexity measures fluency, not correctness. They also say correctness cannot be checked during a debate without ground truth. Their claim is that conformity is a group effect, so the control should act on the group's "debate relationships" (who references whom), not on a per-answer score.

Mechanism, three stages after every round:
- **Group evidence.** Each LLM summarises its reasoning into a conclusion. A text encoder (BGE-M3) embeds the conclusions and the reasoning, and pairwise cosine similarity gives a consensus/divergence matrix. It uses no token probabilities and no task semantics, so it works with closed models.
- **What.** Subjective Logic turns each LLM's row of similarities into a "consultation tendency" toward each peer plus an uncertainty mass. Uncertainty shrinks as total evidence grows.
- **Who.** A Selection agent reads these values and samples a binary mask: does LLM i reference peer j next round. Cutting an edge stops a wrong majority from reaching a correct minority, and it saves tokens.
- **How.** The evidence from the chosen peers is fused with Dempster's combination rule. This separates agreement from conflict, which mean-pooling does not. A Behavior agent maps the fused evidence to each LLM's temperature and top-p: converge when peers agree, explore when they conflict.

The two agents are trained jointly with HAPPO (multi-agent PPO). The reward is only the final answer's correctness, and the LLMs themselves are not fine-tuned. Each LLM also gets a distinct persona, because identical debaters have nothing to debate. Training uses GSM8K for math and ARC-C for QA, then transfers zero-shot to the other tasks.

## Evaluated on
- Beats debate baselines on average accuracy with GPT-4o-mini: math 65.1 vs 57.9 for the best debate baseline (DMAD) and 59.7 for CoT-SC; QA 75.0 vs 69.7.
- Uses fewer tokens than other debate methods: 11.1K vs 22.2K for plain MAD on math, and 8.4K vs 19.5K on QA. CoT-SC costs about the same on math (11.1K) with lower accuracy.
- Holds on closed frontier models. With Claude-4.5-Sonnet, average accuracy is 58.4 vs 49.3 for the best baseline, at 26.4K vs 38.0K tokens. With Gemini-3.1-Flash-Lite it is 60.8 vs 56.7.
- Gains show on hard sets: AIME24 with Claude is 76.7 vs 63.3, and TruthfulQA with GPT-4o-mini is 83.5 vs 77.8 for the best baseline.
- Accuracy keeps rising as agents go from 3 to 8, and it nears its best in fewer rounds. These are read from plots; the text gives no numbers.
- Ablation: removing the Selection agent hurts most, and the paper reads this as peer choice being the main driver. Swapping Dempster fusion for mean-pooling, or removing personas, costs less. The figure values are only in plots.

## Limitations admitted by the authors
- Only reasoning tasks with short answers were tested. The authors list generative tasks, multimodal work, collaborative coding and open-ended planning as future work, so it is unknown whether answer-level similarity works for long outputs.

## What it leaves untried
- It never measures blind conformity directly (for example, how often a correct minority flips to a wrong majority). The claim that it mitigates conformity rests on end accuracy and the ablation, so other explanations are not excluded.
- Similarity between answers is the only evidence, so a confidently wrong consensus looks the same as a right one. The paper gives no test of the case where most debaters share the same error, and no comparison with a ground-truth-free check on that case.
- Training needs labelled tasks and one RL run per task family (GSM8K, ARC-C). Transfer is shown only inside math and QA, and the training cost is not reported against the tokens saved.
