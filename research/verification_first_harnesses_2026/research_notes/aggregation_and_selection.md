# Aggregation and selection in multi-agent LLM systems, 2025 to October 2026: from stated confidence and unanimity to externally grounded rules

Scope note. The background report (research/multiagent_llm_systems/report.md) already records the headline numbers for Choi et al. (martingale result), Bertalanič & Fortuna (85.5% / 70.0% / 32.3 pp / 2.1-3.4x), Hao et al. (37% baseline flips), Wynn et al., Okawa, R²-MAD (one line), Conformal Social Choice (81.9%) and Agent S3 (72.6%). These notes go underneath those lines: mechanism, external signal, full result tables, models, venue, admitted limitations, and the 2026 papers the background does not cover (Consensus is Not Verification, Selection Bottleneck, Budgeted Act-or-Defer, AgentAuditor, VeriHarness, ECMR, SPLIT, DASE, Demystifying MAD, Tran & Kiela, Independent Sampling, diversity audit, wrong-consensus decomposition, adversarial heterogeneity, Consensus Trap, Confident Liar, Wald-SPRT). Review status is given for every paper; "preprint" means arXiv only with no venue listed on the arXiv page as of 21 Oct 2026.

## Key question 1: Which 2025-2026 aggregation rules use a signal the agents did not write, and what is it?

### Takeaway
Six distinct external signals appear in 2025-2026 aggregation rules: (a) ground-truth correctness of past debates turned into per-agent reliability (R²-MAD); (b) a labelled calibration set turned into a conformal threshold over pooled verbalised distributions (Conformal Social Choice) or into a kNN lower confidence bound on correctness (Budgeted Act-or-Defer); (c) a separate judge model reading an execution record rather than the agent's claim (Agent S3 BJudge, Tran & Kiela's Ensemble arm); (d) evidence pulled from the task environment, files, data, constraints (VeriHarness, Best-of-Evidence, ECMR's verify action); (e) inter-agent similarity of reasoning and conclusions, which agents emit but do not author as a confidence claim (DEAR); and (f) a verifier such as unit tests or a reward model with measured true/false-positive rates (SPLIT). Confidence-weighted rules survive only where the confidence has been RL-trained for calibration (Demystifying MAD), and even there the gain over plain majority vote is 0.2-6.2 points on 7-8B models.

### Cited Findings

#### R²-MAD (Remember and Reweight), arXiv 2609.03619, v1 3 Sep 2026, comments field "EMNLP 2026 Findings"
- Mechanism: each memory case stores the debate state, every agent's response, the answer, whether agent i was correct, and an outcome reward (1 correct / 0 wrong). Reliability of peer j is a similarity-weighted average of j's correctness over retrieved cases, weighted by cosine similarity between j's current response and its past responses. The weight is applied at the prompt level: a peer response is labelled "high confidence" if the score exceeds 0.55 and "low confidence" if below 0.45, otherwise unlabelled. Final answer in the MAD baseline is majority vote over last-round responses; the paper does not state a different final aggregator for R²-MAD — [R²-MAD full text](https://arxiv.org/html/2609.03619)
- External signal: benchmark correctness labels for past debates. The authors say a verifier or execution feedback could supply the label instead, but this is not tested — [R²-MAD full text](https://arxiv.org/html/2609.03619)
- Models and tasks: Qwen2.5-7B-Instruct, Qwen3-8B, Gemma-3-4B-IT on MATH500 Level-5 (134 test), MMLU-Pro Economics (211 test of 844), MMLU-Pro Engineering (242 test of 969), TruthfulQA (166 test of 664). Memory is built from a split of the same dataset (easier MATH levels for MATH500; random or stratified splits otherwise) — [R²-MAD full text](https://arxiv.org/html/2609.03619)
- Main result (Table 1, average over four benchmarks): Qwen2.5-7B CoT 0.565, Self-Consistency (9 samples) 0.593, MAD 0.571, MAD-M2 0.501, R²-MAD 0.607. Qwen3-8B: 0.672 / 0.706 / 0.771 / 0.732 / 0.780. Gemma-3-4B: 0.443 / 0.476 / 0.484 / 0.448 / 0.505. So the gain over self-consistency is +1.4, +7.4 and +2.9 points, and over plain MAD +3.6, +0.9 and +2.1 points — [R²-MAD full text](https://arxiv.org/html/2609.03619)
- Larger models (Appendix B.6, Table 7, CoT / MAD / R²-MAD averages): Llama-3.3-70B-Instruct 0.644 / 0.702 / 0.717; GPT-4o-mini 0.606 / 0.648 / 0.661. On TruthfulQA R²-MAD ties MAD at 70B (0.874) and is below MAD for GPT-4o-mini (0.861 vs 0.874). Self-consistency is not reported at this scale — [R²-MAD appendices](https://arxiv.org/html/2609.03619)
- Cost (Appendix B.7, Economics only): Qwen2.5-7B SC 5.75K tokens / 0.62 s, MAD 4.44K / 0.49 s, R²-MAD 5.41K debate + 2.25K summary tokens / 0.96 s. Qwen3-8B: SC 14.67K / 5.65 s, MAD 6.16K / 3.75 s, R²-MAD 6.38K + 1.85K / 6.28 s. Roughly 1.5-2x MAD wall-clock — [R²-MAD appendices](https://arxiv.org/html/2609.03619)
- Baselines not compared: ReConcile, DebUnc, any confidence-weighted vote — [R²-MAD full text](https://arxiv.org/html/2609.03619)
- Admitted limitations: extra per-round computation; requires an outcome signal for past debates; memory is built offline and fixed at test time, so it "may degrade if deployment tasks differ substantially"; a memory built from mistaken trajectories could reinforce error, so the authors recommend auditing the bank; continual updates and weaker supervision left to future work — [R²-MAD full text](https://arxiv.org/html/2609.03619)

#### Conformal Social Choice, arXiv 2604.07667, v1 9 Apr 2026, v2 20 Oct 2026, preprint
- Mechanism: heterogeneous agents emit verbalised probability distributions over the answer options; these are pooled by a linear opinion pool; split conformal prediction on a labelled calibration half yields a prediction set with marginal coverage >= 1-alpha "without assumptions on individual model calibration"; a singleton set means act autonomously, a larger set means escalate to a human — [Conformal Social Choice abstract](https://arxiv.org/abs/2604.07667)
- External signal: labelled calibration data, each domain split 50/50 into calibration and test. MMLU-Pro domain sizes 798 (Psychology) to 1,351 (Math) — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Models: Claude Haiku 4.5, DeepSeek-R1, Qwen-3 32B via AWS Bedrock; a second ensemble of Haiku, Nova Pro, DeepSeek-R1 in Appendix L. Tasks: eight MMLU-Pro domains (10 options), LogiQA (n=8,678, 4 options), GPQA Extended (n=546, 4 options). 3 agents x 4 rounds = 12 LLM calls per question — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Coverage: 93.0-97.6% at alpha=0.05 and 87.6-93.2% at alpha=0.10 across the three benchmarks; repeated random splits on MMLU-Pro stay within 1.3 points of target on average — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Wrong-consensus interception: of 586 final-round wrong-consensus cases on MMLU-Pro, 81.9% (about 480) have non-singleton round-3 sets at alpha=0.05; 90.8% on LogiQA; 87.3% on GPQA. Over-rejection of correct consensus 31.9% — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Singleton accuracy among cases resolved before the final round: 90.0-96.8% versus 67.9-94.9% for consensus stopping; largest gap Law 90.0% vs 67.9% (+22.1 pp). The authors call this "a selection effect, not a reasoning improvement" — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Against scalar rules at round 3 on MMLU-Pro: conformal flags 81.9% of wrong consensus vs 79.4% for fixed top-1 probability (tau=0.95), 79.7% calibrated top-1, 80.0% calibrated entropy; over-rejection 31.9% vs 26.8%, 33.5%, 35.1%. The paper states the distinct value of conformal is the finite-sample fixed-round coverage guarantee and explicit candidate sets, not better interception — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Majority vote baseline: debate with majority voting is a point-estimate baseline at 66.7-94.2% across domains; no confidence-weighted vote comparison found — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Admitted limitations: coverage is marginal, not per-instance; adaptive first-singleton stopping is "evaluated empirically and not covered by this guarantee"; distribution shift (e.g. calibrating on one exam year, testing another) violates exchangeability, online conformal suggested; verbalised probabilities are noisy and prompt-sensitive, parsing failures (0.77%) default to uniform; closed-set multiple choice only; 12 calls per question — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)

#### Budgeted Act-or-Defer with Local Reliability Bounds, arXiv 2606.29654, v1 28 Jun 2026, preprint (same group as Conformal Social Choice)
- Mechanism: each round the debate prefix is mapped to a low-dimensional state; a k-nearest-neighbour lower confidence bound on state-conditional correctness is computed from calibration data; the system acts only when the bound clears a user-declared wrong-action budget beta, otherwise defers to a human. Wrong-action risk decomposes as beta = delta + alpha + epsilon_act (calibration failure, residual action risk, representation gap). The guarantee is conditional, not distribution-free — [Act-or-Defer abstract](https://arxiv.org/abs/2606.29654)
- External signal: labelled calibration examples whose debate states are near the current one. Each benchmark split 50/50 train/test; training half split 20/80 into modulus-estimation set and kNN database (roughly 220 database instances for GPQA, the fetch's estimate from the stated splits) — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- Models: Claude Haiku 4.5, DeepSeek-R1, Qwen-3 32B, 4 rounds. Six benchmarks: MMLU-Pro (8,312), LogiQA (8,678), ARC-Challenge (2,590), BBH (2,395), MuSR (756), GPQA (546) — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- Results (Act% / accuracy on acted / budget used WA/beta): MMLU-Pro 71.1 / 93.9 / 0.12; LogiQA 27.9 / 88.9 / 0.10; ARC 75.5 / 97.1 / 0.11; BBH 84.4 / 96.4 / 0.09; GPQA 53.3 / 82.5 / 0.12; MuSR 9.0 / 70.3 / 0.04. Consensus stopping (act when all agree) on MMLU-Pro: 94.5 / 84.5 / 0.41; Confidence Threshold (top prob >= 0.90): 69.8 / 84.5 / 0.41; Conformal Risk Control: 100 / 79.9 / 0.53. On GPQA consensus acts on 87.0% at 71.3% accuracy using 0.37 of budget — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- The authors state that at matched automation, tuned scalar thresholds reach similar accuracy; the claimed advantage is "prospective budget conversion, not better subset quality" — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- Majority vote and Conformal Social Choice are not among the nine baselines — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- Admitted limitations: conditional guarantee relying on a valid bias envelope and representation-gap bound; diagnostics do not prove the gap is small; low activation on GPQA and MuSR (MuSR activates on only 2 of 10 splits) reflects small samples and high base error; "geometry-sufficiency trade-off" named as the central open challenge — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)

#### Agent S3 / Behavior Best-of-N (BJudge), arXiv 2510.02250, v1 2 Oct 2025, v2 3 Feb 2026, preprint
- Mechanism: N independent rollouts from the same initial VM state. Each rollout is converted into a "behavior narrative": per step, a generator VLM sees the pre-action screenshot, the action and the post-action screenshot and writes facts about what changed (pointer actions get a marker and zoomed crop). The judge sees all candidate narratives at once in a single multiple-choice call and picks one index (not a pairwise tournament) — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- External signal: the screenshot-grounded execution record, read by a separate judge model. No agent self-report or vote is used — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Results, OSWorld 361 tasks, 100 steps: Agent S3 single rollout with GPT-5 62.6% (average over 10 runs); BJudge N=10 69.9% with GPT-5, 60.2% with GPT-5 Mini; 72.6% with GPT-5 + Opus 4.5 (5 rollouts each), vs the stated human level 72.36%; prior SoTA GTA1 63.4%. Appendix E: 64.73 (N=2), 66.12 (N=3), 68.04 (N=4), 66.86 (N=5). Section 4.6: +4.25% at budget 200 (N=4), +6.38% at budget 1000 (N=10) over a single agent — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Other benchmarks (GPT-5, N=3): WindowsAgentArena 56.6% vs 50.2% Agent S3 single; AndroidWorld 71.6% vs 68.1% — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Judge quality: 78.4% agreement with benchmark labels on the 159-task Judge Subset, 92.8% by human alignment; on the full set 69.9% / 76.3%. Pass@N upper bound 80.5% (All mixture) and 79.1% (GPT-5 + Opus), so the judge recovers about 72.6 of a possible 79.1. Narrative representation ablation (10 GPT-5 Mini rollouts): behavior narratives 60.2%, naive captioning 56.8%, screenshot-only 56.0%, trajectory summary 55.0%. An independent per-trajectory 1-5 scorer (adapted WebJudge) plateaus near the average rollout and drops at N=10. No majority-vote baseline is reported — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Cost (Table 8, N=10, GPT-5): a rollout costs about $0.72 and 891 s; narrative generation $0.11 and 433 s; judging $0.03 and 226 s, so judging is about 5x cheaper than one rollout, but ten rollouts are 10x the single-agent cost — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Open-source judge: Qwen3-VL-30B-A3B-Thinking for both narrative and judging reaches 40.9% vs 51.5% with GPT-5 for both — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Admitted limitations: requires multiple independent rollouts from the same initial state (feasible with VM snapshots, not on a live desktop); shared external state (email, cloud storage, carts) causes cross-run interference; of 12 analysed failures 8 were narrative-generation hallucinations — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)

#### VeriHarness, arXiv 2610.00972, v1 1 Oct 2026, preprint (Google Cloud AI Research)
- Mechanism: ten rollouts per task; the same model as the generator is turned into a verifier with a workspace, evidence tools and reusable skills. A "disagreement resolver" checks competing claims against source files, data and constraints; a "consensus challenger" tests claims all rollouts share and looks for requirements every rollout omitted; a fresh-context adjudicator produces a base rollout, a revision plan and unresolved claims — [VeriHarness](https://arxiv.org/html/2610.00972)
- External signal: evidence from the task environment. The paper states "unanimity can hold even when every candidate is incorrect" — [VeriHarness](https://arxiv.org/html/2610.00972)
- Results, average over APEX-Agents, Workspace-Bench Lite, WorkBuddy Bench, SpreadsheetBench 2, JobBench (native scales): Gemini 3.5 Flash single rollout 47.2, majority voting 47.5, best-of-N with judge 47.3, VeriHarness select 51.6, with revision 53.4; Claude Opus 4.8: 49.6 / 50.4 / 50.6 / 53.7 / 56.1. Selection oracle 62.7 (Flash) and 63.1 (Opus). So majority vote and a plain judge add 0.1-1.0 points on these long-horizon tasks while environment-grounded verification adds 4.1-4.4 by selection alone — [VeriHarness](https://arxiv.org/html/2610.00972)
- Cost: the rollout pool cost over $100,000; about 26,000 rollouts released — [VeriHarness](https://arxiv.org/html/2610.00972)
- Admitted limitations: ten rollouts only; no calibrated per-rollout scores; same-model verification only, so harness gains are not separated from capability gaps; added latency — [VeriHarness](https://arxiv.org/html/2610.00972)

#### DEAR (Dynamically rEgulating debAte Relationships), arXiv 2608.03648, v1 4 Aug 2026, preprint
- Mechanism: "group evidence" is built from pairwise cosine similarities of conclusion embeddings and reasoning embeddings (BGE-M3 encoder), averaged to e_ij; Subjective Logic converts the evidence into belief masses b_ij = e_ij/S_i toward each peer and an uncertainty u_i = V/S_i. A Selection RL-agent picks which peers to reference and a Behavior RL-agent sets generation behaviour, trained jointly with multi-agent RL — [DEAR full text](https://arxiv.org/html/2608.03648)
- Signal: the agents' own texts, but compared across agents (consensus and divergence) rather than read as self-reported confidence. This is internal to the group, not external to it — [DEAR full text](https://arxiv.org/html/2608.03648)
- Claim on confidence and perplexity: the paper asserts they "fail to reflect the correctness of reasoning and may even exacerbate blind conformity", resting on cited prior work ([18]) rather than its own measurement; no numbers are given — [DEAR full text](https://arxiv.org/html/2608.03648)
- Results, GPT-4o-mini (accuracy % / K tokens per task), Math (GSM8K, AIME24, GSM-Hard, MATH-500) and QA (ARC-C, MMLU-Pro Health, TruthfulQA, GPQA Diamond): DEAR 65.1 / 11.1 and 75.0 / 8.4; CoT-SC 59.7 / 11.1 and 70.3 / 9.3; MAD 56.9 / 22.2 and 69.6 / 19.5; Majority Voting 55.5 / 2.0 and 68.9 / 1.7; DMAD 57.9 / 25.4 and 69.1 / 23.6; CortexDebate 56.5 / 29.8 and 69.7 / 20.4 — [DEAR full text](https://arxiv.org/html/2608.03648)
- Larger closed models (Table 2 averages, accuracy / K tokens): Claude-4.5-Sonnet DEAR 58.4 / 26.4 vs MAD 48.5 / 35.5; Gemini-3.1-Flash-Lite DEAR 60.8 / 15.7 vs MAD 53.1 / 30.7 — [DEAR full text](https://arxiv.org/html/2608.03648)
- Limitations: the paper has no Limitations section; the conclusion lists only future work (generative tasks, multimodal, coding, planning). DebUnc and ReConcile are not compared — [DEAR full text](https://arxiv.org/html/2608.03648)

#### AgentAuditor, arXiv 2602.09341, v1 10 Feb 2026, v2 3 Sep 2026, preprint
- Mechanism: agent traces are arranged into a Reasoning Tree showing where agents agree and diverge; at divergence points an adjudicator compares the evidence on each branch instead of counting votes. Anti-Consensus Preference Optimization (ACPO) trains the adjudicator on "evidence-verified" preference labels to resist majority cues — [AgentAuditor](https://arxiv.org/abs/2602.09341)
- Result: up to 5 points absolute over majority voting across four MAS frameworks and multiple reasoning benchmarks; the abstract page gives no LLM-as-judge figures despite the title, and does not name models or what verifies the evidence — [AgentAuditor](https://arxiv.org/abs/2602.09341)

#### ECMR, arXiv 2610.17869, v1 13 Oct 2026, preprint
- Mechanism: a controller over frozen role-conditioned LLMs reads a state summary (answer concentration, support diversity and independence, contradictions, verification history, remaining budget) and picks propose / challenge / verify / arbitrate / diversify / correct-role / stop. It names "semantic false consensus": a confident group answer backed by narrow, duplicated or correlated rationales — [ECMR](https://arxiv.org/abs/2610.17869)
- Results on 9,000 held-out records from MedQA, CaseHOLD, FinQA: pooled accuracy 62.1% to 84.9%, false-consensus rate 40.7% to 17.0%, evidence-support rate 58.0% to 88.7%; shuffling the state costs 11.7 accuracy points for 0.7 fewer rounds. ECMR-Full uses the largest token budget; the authors present it as strongest absolute reliability, not efficiency. Backbone models not named on the abstract page — [ECMR](https://arxiv.org/abs/2610.17869)

#### SPLIT (Sample, Mix, or Verify?), arXiv 2610.23255, v1 16 Oct 2026, preprint (Microsoft Research India)
- Mechanism: a small labelled pilot estimates per-task difficulty, cross-model shared blind spots, and verifier true-positive rate tau, false-positive rate f and repeated-call correlation kappa; an exact formula for P(submitted answer correct) then chooses how to split a fixed budget across samples, generator models and verifier calls — [SPLIT](https://arxiv.org/html/2610.23255)
- Results: SPLIT lands within 0.02-0.8 pp of the best allocation in hindsight across seven benchmarks, 26 models, 175 agent systems and six verifier kinds; every fixed rule loses at least 2.5 points somewhere. Verification ceiling: majority voting over Llama-3-8B-Instruct on MATH stays near 43% while coverage reaches 98%. Nine judge calls vs one barely move MATH-500 (0.717 vs 0.718) but add +1.2, +3.3, +4.8 on GPQA at N=4, 16, 64. Shared blind spots: Llama-3-8B and Gemma-7B per-problem solve rates correlate 0.80 on MATH, so assuming independence overstates mixing gain by up to about 7 points. On SWE-bench Verified a fixed 0.5 verifier threshold lowers resolve rate from 32.5% to 25.1% at one rollout — [SPLIT](https://arxiv.org/html/2610.23255)
- Admitted limitations: estimators assume the pilot represents deployment; one-parameter price model; candidates assumed conditionally independent given the task; forecasting gains large only for simulated verifiers — [SPLIT](https://arxiv.org/html/2610.23255)

#### Best-of-Evidence, arXiv 2607.20950, v1 23 Jul 2026, preprint
- Mechanism: keeps the best-of-N pool fixed, models reusable claims in a signed candidate-factor graph, and spends a limited evidence budget on partial checks (a finding, span, value, region or relation) likely to change the choice; zero budget reduces to the underlying BoN decision. Theory: residual evidence capacity bounds any gain; shared factor queries cost O(log K) vs Theta(K). Four medical VQA settings; no numbers on the abstract page; the authors say it does not help when evidence is unreliable or not decision-relevant — [Best-of-Evidence](https://arxiv.org/abs/2607.20950)

#### The confidence-weighted counterpoints
- Demystifying MAD (Cambridge/Sheffield), arXiv 2601.19921, v3 3 Jun 2026, preprint: verbalised 0-10 confidence trained with GRPO + LoRA on a log calibration reward. Calibration improves (Llama-3.1-8B Brier 0.217 to 0.069, ECE 0.257 to 0.167, AUROC 0.644 to 0.763; Qwen-2.5-7B Brier 0.212 to 0.046, AUROC 0.576 to 0.754; self-consistency AUROC about 0.85). Confidence-modulated debate vs majority vote vs vanilla 5x5 debate: Qwen GSM8K 0.910 / 0.908 / 0.847; MMLU-All 0.769 / 0.764 / 0.727; GPQA (OOD) 0.350 / 0.335 / 0.339; ARC-C 0.911 / 0.880 / 0.882. Llama ARC-C 0.882 / 0.832 / 0.802. The authors observed reward hacking (agents stopped engaging) and added a keyword engagement reward. Admitted limitations: assumes calibrated confidence correlates with correctness; homogeneous agents only; heterogeneous models left to future work — [Demystifying MAD](https://arxiv.org/html/2601.19921v3)
- Roundtable Policy, arXiv 2509.16839, v2 11 Feb 2026, preprint: "weighted consensus of multiple LLMs" on heterogeneous scientific tasks; the abstract page does not state how confidence is measured or give numbers against majority vote — [Roundtable Policy](https://arxiv.org/abs/2509.16839)
- The Confident Liar, ACL 2026 Student Research Workshop, pp. 1361-1375: token log-probabilities over reasoning tokens track judged reasoning quality about twice as strongly for the Constructor role as for the Auditor; AUROC for detecting critical failures 0.804 (Constructor) vs 0.634 (Auditor); single domain (rubric scoring), math and factual QA proposed only — [Confident Liar](https://aclanthology.org/2026.acl-srw.121/)

### Inferences
- Every rule that beats majority vote by more than about 2 points on a hard task (Agent S3 +7.3 over single rollout at N=10, VeriHarness +4.1 to +4.4 by selection, Act-or-Defer and Conformal on the accuracy of acted-on items, AgentAuditor up to +5) uses a signal that is either a label, an execution record or environment evidence. The two rules that stay inside the agents' words (DEAR's similarity, Demystifying's trained confidence) report smaller or model-dependent gains and are evaluated at 4-8B or on GPT-4o-mini.
- The three label-dependent rules (R²-MAD, Conformal, Act-or-Defer) all split the benchmark itself to get the label, so none has been shown to work with labels from a different distribution than the test set.
- "Externally grounded" and "cheaper" are in tension: Agent S3 at N=10 is roughly 10x the rollout cost, Conformal needs 12 calls per question, VeriHarness released a $100k pool. Only DEAR and Wald-SPRT claim to save tokens.

### Gaps
- R²-MAD never tests a verifier or execution signal in place of ground-truth labels, although the paper names that substitution as possible.
- Roundtable Policy's confidence signal and numbers are not on the abstract page; I did not fetch the full text, so its claimed gains are unverified here.
- AgentAuditor's "evidence-verified" labels: what verifies them is not stated on the abstract page.
- ECMR and AgentAuditor do not name backbone models on their abstract pages.

## Key question 2: What is the measured gain over majority vote and over confidence-weighted vote, at matched compute?

### Takeaway
At matched compute the honest numbers are small or negative for deliberation and modest for selection: debate adds 0.00 pp over self-reflection at 57% more tokens (Hao et al.), single agents match or beat every MAS variant at equal thinking tokens from 500 tokens up (Tran & Kiela), polling-style aggregation at about 25x cost gives no consistent gain over one sample (Consensus is Not Verification), and confidence-weighted voting is reported as providing no benefit in the one study that tests it against majority vote on open models from 4B to 235B. Selection with a grounded judge adds 4-7 points on OSWorld and long-horizon workspace tasks but is not compute-matched against a single agent given the same budget.

### Cited Findings
- Hao et al. (preprint, v2 18 Oct 2026), all 4,900 MMLU-Pro questions, five GPT-4o agents, majority vote accuracy / tokens per question: single instance 75.13% / 700; aggregation-only 76.22% / 3,500; self-reflection 77.35% / 4,469; peer-stance-only debate 77.18% / 4,522; full-reasoning debate 77.35% / 7,019. Paired difference full reasoning vs self-reflection 0.00 pp (95% CI -0.59 to +0.59). On disagreement questions individual accuracy rises from 42.17% to 45.87% but the group vote does not — [Hao et al. full text](https://arxiv.org/html/2606.00820v2)
- Tran & Kiela (preprint, v2 11 Apr 2026), equal thinking-token budgets, averages over four model/dataset settings on 4-hop FRAMES and MuSiQue: at 1k tokens SAS 0.418 vs Sequential 0.379, Debate 0.388, Ensemble-with-judge 0.333; at 10k tokens SAS 0.426 vs Debate 0.420, Ensemble 0.420, Roles 0.423. At 100 tokens MAS leads (Debate 0.370 vs SAS 0.290), attributed to the single model producing no useful trace. DeepSeek-R1-Distill-Llama-70B on MuSiQue: SAS 0.407 vs best MAS 0.334 at 1k, 0.417 vs 0.360 at 10k; on FRAMES at 10k Ensemble 0.458 vs SAS 0.456. Gemini 2.5 Pro on MuSiQue: Debate leads at 1k-10k (0.458 vs 0.428 at 10k), within overlapping bootstrap CIs. Models: Qwen3-30B, DeepSeek-R1-70B, Gemini 2.5 Flash and Pro. Admitted limitations: budgets are caps not forced spend; Gemini thinking-token accounting approximate; text-only — [Tran & Kiela](https://arxiv.org/html/2604.02460v2)
- Consensus is Not Verification (preprint, v1 20 Feb 2026, Stanford/Koyejo group): Gemma-3-4B, GPT-oss-20B, GPT-oss-120B, Qwen3-32B, Qwen3-235B; 25 samples at each of T=0.7 and 1.0 (50 per question-model, 375,000 responses); aggregators Majority Vote, Highest Confidence, Confidence-Weighted Vote, Prediction-Weighted Vote, Surprisingly Popular. No method consistently beats a single sample at about 25x cost; GPT-oss-120B on BoolQ 80.1% individual vs 80.0% majority. One exception: Gemma-3-4B on the 35-item HLE binary subset, 27.3% individual vs 37.4% prediction-weighted, CI about 20-52%. Confidence-weighted voting "provides no benefit"; self-reported confidence correlates weakly with accuracy and about as strongly with agreement; reliability diagrams show confidence rising faster than accuracy. Admitted limitations: binary questions only, verbalised confidence only, small HLE and forecasting sets — [Consensus is Not Verification full text](https://arxiv.org/html/2603.06612v1)
- Bertalanič & Fortuna (ACM Conference on AI and Agentic Systems per comments field; v1 29 Apr 2026): N=10 homogeneous agents, R=3 rounds, Qwen2.5-7B, Llama-3.1-8B, Ministral-3-8B on GSM-Hard and MMLU-Hard; debate uses 2.1-3.4x the tokens of isolated self-correction, up to 28,631 tokens per problem, with plurality voting as the only aggregator; the oracle gap of up to 32.3 pp is correct answers present in the pool that plurality discards. Scope stated as "within the 7-8B parameter class" and "homogeneous teams without structured roles" — [Bertalanič & Fortuna](https://arxiv.org/abs/2605.00914)
- Wynn, Satija & Hadfield (preprint v2 13 Oct 2025; workshop version ICML MAS 2025): 100 items per task, 5 seeds, 2 rounds, GPT-4o-mini, Llama-3.1-8B, Mistral-7B on CSQA / MMLU / GSM8K. Majority vote before debate vs after: three Mistral 44.4 to 39.4 / 33.6 to 24.4 / 43.6 to 46.4; three Llama 63.0 to 58.6 / 61.6 to 57.8 / 87.6 to 84.2; two Llama + one Mistral 58.2 to 50.2 / 51.8 to 43.6 / 82.6 to 75.8; diverse one-of-each 66.6 to 65.4 / 57.8 to 63.4 / 86.8 to 90.2; two GPT + one Llama 74.8 to 74.0 / 82.6 to 81.0 / 93.6 to 94.6. CSQA fell in every configuration. A payoff-for-correctness prompt did not reduce correct-to-incorrect flips and in many cases increased them. Exact flip rates are figure-only — [Wynn et al. full text](https://arxiv.org/html/2509.05396v2)
- Agent S3: BJudge N=10 with GPT-5 is 69.9% vs 62.6% single rollout (+7.3), at roughly 10x rollout cost plus $0.14 per task for narratives and judging; no compute-matched single-agent arm (e.g. one rollout given 10x the step budget) is reported — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- VeriHarness: majority vote adds +0.3 (Flash) and +0.8 (Opus) over a single rollout; best-of-N with a plain judge +0.1 and +1.0; VeriHarness selection +4.4 and +4.1; oracle +15.5 and +13.5. Ten rollouts per task, so none of these arms is compute-matched to the single rollout — [VeriHarness](https://arxiv.org/html/2610.00972)
- Demystifying MAD: trained-confidence weighting over plain majority vote on 7-8B models: +0.2 (Qwen GSM8K), +0.5 (Qwen MMLU-All), +1.5 (Qwen GPQA), +3.1 (Qwen ARC-C), +6.2 (Llama GPQA), +5.0 (Llama ARC-C), -0.1 (Llama HellaSwag). Vanilla debate is below majority vote on most rows (Qwen GSM8K 0.847 vs 0.908). Training cost about 1,500 A100 GPU hours — [Demystifying MAD](https://arxiv.org/html/2601.19921v3)
- DEAR vs majority voting on GPT-4o-mini: +9.6 points on math and +6.1 on QA, but at 11.1K vs 2.0K and 8.4K vs 1.7K tokens, so 5x the budget; vs CoT-SC at equal math tokens (11.1K): +5.4 — [DEAR full text](https://arxiv.org/html/2608.03648)
- Dong & Shigida, When Independent Sampling Outperforms Agentic Reasoning (preprint, v1 8 May 2026): 216 Codeforces problems, Div 1-3; repeated independent sampling (k-shot) "consistently achieves a better accuracy-cost and accuracy-query tradeoff" than agent frameworks, persisting under prompt caching; proves a cost-optimal solver minimises log failure likelihood per dollar. Debate is not an arm; selection rule and model sizes not on the abstract page — [Independent Sampling](https://arxiv.org/abs/2605.08478)
- Wald-SPRT governor (preprint, v1 18 May 2026): gpt-5, claude-opus-4-6, gemini-2.5-pro as agents with claude-opus-4-6 as judge; on GSM8K 1.01 average rounds (4.06 calls) at 97.0% vs 99.0% for fixed 5-round debate at 15 calls (3.7x fewer calls, -2 points); on MMLU the judge signal's calibrated KL collapses to about 0 and the rule hits the cap on 99.5% of items at 2.1x cost. The author states SPRT "does not make debate more accurate" — [Wald-SPRT](https://arxiv.org/abs/2605.19193)

### Inferences
- Across the four compute-matched studies (Hao, Tran & Kiela, Consensus is Not Verification, Bertalanič & Fortuna) the gain of debate over the cheapest aggregator at the same budget is within noise or negative, from 7B to 235B and GPT-4o. The only compute-matched arm where a multi-agent variant leads is Gemini 2.5 Pro Debate on MuSiQue, and the authors mark it as inside overlapping CIs.
- The selection gains (Agent S3, VeriHarness) are real against a single rollout but are not compute-matched. The honest comparison, one agent given N times the step budget, has not been run on OSWorld or the workspace benchmarks.
- Confidence weighting splits by provenance of the confidence: untrained verbalised confidence gives no benefit (Consensus is Not Verification, 4B-235B); RL-trained verbalised confidence gives 0.2-6.2 points on 7-8B (Demystifying), with a training bill of about 1,500 GPU hours.

### Gaps
- No 2026 paper reports a head-to-head of grounded best-of-N selection against a single agent at the same total compute above 32B. Tran & Kiela's Ensemble arm is the closest (judge over independent candidates at equal thinking tokens, 70B and Gemini 2.5 Pro) and it does not beat a single agent on average.
- Wynn et al.'s flip rates and sycophancy numbers exist only in figures; the text gives none.
- Dong & Shigida's abstract page does not state the selection rule or model sizes.

## Key question 3: Does any paper isolate selection from deliberation and show which carries the gain?

### Takeaway
Four 2026 papers isolate the two and all point the same way: the gain lives in selection over independent draws, and deliberation adds nothing measurable once self-reflection and voting are controlled. Conformal Social Choice says its +22.1 pp is "a selection effect, not a reasoning improvement"; Hao et al. find peer reasoning adds 0.00 pp to the vote; the Selection Bottleneck paper shows a diverse team wins at 0.810 only under judge selection and falls to chance under synthesis; VeriHarness shows a grounded verifier beats both majority vote and a plain judge over the same fixed pool.

### Cited Findings
- Conformal Social Choice: "Among cases reaching a singleton before the final round, accuracy is 90.0-96.8% on MMLU-Pro, up to 22.1pp above consensus stopping", which the authors call "a selection effect, not a reasoning improvement"; "the debate does not become more accurate; the conformal layer makes its failures actionable" — [Conformal Social Choice](https://arxiv.org/abs/2604.07667)
- Hao et al.: full-reasoning debate "provides no additional majority-vote gain over self-reflection while using 57% more tokens"; among reasoning-only peer adoptions (n=487) 29.98% are corrections, 34.09% new errors, 35.93% wrong-to-wrong; among strict-conformity adoptions (n=960) 36.35% / 30.73% / 32.92%. Support-standardised, beneficial exceeds harmful adoption (33.12% vs 24.36% stance-only; 40.42% vs 32.09% full reasoning), yet the aggregate vote does not move. An answer-agnostic suppression of the top 20% most adoption-prone cases cuts harmful adoption by 1.44 pp and beneficial by 2.12 pp, accuracy -0.77 pp (CI -3.46 to +2.02). The paper cites Choi et al. for the finding that initial majority voting explains much of the gain attributed to multi-round debate. Admitted limitations: homogeneous GPT-4o, one round of peer exposure, multiple choice only — [Hao et al. full text](https://arxiv.org/html/2606.00820v2)
- Selection Bottleneck (Maryanskyy, Budnikov, Kaliyev; Applied Sciences 16(10), 4914, 2026, published; arXiv 2603.20324): a closed-form crossover threshold s* in aggregation quality decides whether diversity helps or hurts. In 42 tasks across 7 categories (N=210 evaluations), a diverse team with judge-panel selection has win rate 0.810 vs the single-model baseline; the homogeneous team 0.512, near chance (Glass's delta = 2.07); MoA-style synthesis is preferred over baseline in 0 of 42 tasks (delta WR = +0.631 for judge selection over synthesis); independent judges agree at Spearman rho = 0.90. Exploratory, not pre-registered: adding a weaker model improved performance while reducing cost (p < 10^-4). Conclusion: "selector quality may matter more than generator diversity in single-round generate-then-select pipelines". Models not named on the abstract page — [Selection Bottleneck](https://arxiv.org/abs/2603.20324)
- VeriHarness, same fixed pool of ten rollouts: majority vote 47.5 / 50.4, judge best-of-N 47.3 / 50.6, environment-grounded selection 51.6 / 53.7, oracle 62.7 / 63.1 (Flash / Opus). Revision after selection adds a further 1.8-2.4 — [VeriHarness](https://arxiv.org/html/2610.00972)
- Tran & Kiela: Debate (two debaters critique each other, judge picks) vs Ensemble (independent candidates, judge picks) at equal thinking tokens: at 10k tokens Debate 0.420 and Ensemble 0.420 on average; at 1k Debate 0.388 vs Ensemble 0.333. Both below SAS 0.426 / 0.418 — [Tran & Kiela](https://arxiv.org/html/2604.02460v2)
- DASE (Medina, preprint v2 14 May 2026): an adaptive stopping rule over iterative ensemble deliberation; "adaptive stopping matters more than how much information is injected between rounds": on AIME-300 injection bandwidth accounts for 0.3 pp (n.s.); on GPQA-Extended at the 120B tier sparse injection (about 15 tokens per worker per round) reaches 70.9% vs 72.2% for dense injection (about 600 characters), which halves right-wall coverage. Commit-type partition: right-wall commits 81.1% vs left-wall 41.5% on GPQA-Extended (70B ensemble); 98.3% vs 72.8% on AIME 2010-2023 (120B ensemble), equivalent to Opus 4.6 verbalised confidence at matched coverage (25.7 pp gap, p=0.873) but disagreeing on 37% of routing assignments. No majority-vote baseline at fixed N — [DASE](https://arxiv.org/abs/2605.04236)
- Agent S3: an independent per-trajectory scorer (adapted WebJudge) plateaus near the average rollout and drops at N=10, while comparative selection over all narratives at once rises with N; the gain is in the comparison, not in agents revising — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Bertalanič & Fortuna: the oracle gap of up to 32.3 pp is correct answers present in the pool that plurality voting discards, which "implicitly compares selection against voting" though no selector is run — [Bertalanič & Fortuna](https://arxiv.org/abs/2605.00914)

### Inferences
- The isolation is cleanest in Hao et al. (same agents, same questions, peer information added or withheld) and in VeriHarness (same ten rollouts, four selectors). Both find the pool already contains the answer and the rule that reads the pool decides the outcome. Deliberation changes individual answers (Hao: +3.7 points on disagreement items) without changing the vote, because corrections and new errors nearly cancel (29.98% vs 34.09%).
- The Selection Bottleneck result reframes the heterogeneity finding: diversity helps only above a selector-quality threshold, which is why Self-MoA (homogeneous) wins under synthesis and MoA (diverse) wins under judge selection.
- DASE's finding that injection bandwidth is worth 0.3 pp while the stopping rule is worth 25-40 pp of acted-on accuracy is the same conclusion from the stopping side.

### Gaps
- No paper runs the four-cell design (independent draws vs deliberation) x (vote vs grounded selector) on one task above 32B with matched compute. Hao et al. is GPT-4o with majority vote only; VeriHarness has no deliberation arm; Tran & Kiela has both arms but only a plain judge.
- The Selection Bottleneck paper's closed-form threshold is a model; the abstract page does not show how well it fits the 42-task data beyond direction.

## Key question 4: How do these rules handle the case where all agents are wrong together (shared misconception)?

### Takeaway
Shared wrong answers are measured as common (53% of MATH questions where several models err share the same wrong answer; wrong-consensus rate 40.7% before ECMR; 586 wrong-consensus cases at round 3 on MMLU-Pro) and every aggregator that reads only agents' outputs is blind to them by construction. Calibration-based rules convert them into escalations (81.9-90.8% intercepted, at 31.9% over-rejection); environment-grounded verifiers test the shared claim directly (VeriHarness's consensus challenger); heterogeneity dampens but does not remove the phase transition to biased consensus (Okawa); R²-MAD reduces correct-to-wrong flips on the wrong-majority subset but all methods stay below 10% accuracy on its hardest subset.

### Cited Findings
- Consensus is Not Verification: on 53% of MATH questions where multiple models err, they converge on the same wrong answer; MATH plurality-wrong rates 3.9-25.8% with the most common wrong answer taking 65-87% of wrong responses; AIME plurality-wrong 3.9-75.8%, concentration 20-63%; on 10,000 random 32-character prompts with a forced A-D choice, models still agree above chance with correlations "as high as 0.35"; the plurality answer flips in only 2.9% of cases between T=0.7 and T=1.0. Models predict vote shares much better than they identify correct answers (Figure 6; no coefficient in text). The discussion proposes predicted consensus as a risk flag for retrieval or deferral but does not test it — [Consensus is Not Verification full text](https://arxiv.org/html/2603.06612v1)
- Decomposing Wrong-Consensus Agreement (Zhang et al., preprint v2 31 Aug 2026): normalised agreement Gamma is split into a "mechanical" part explained by a per-question answer preference alone and a residual; coverage phi = mechanical / empirical. GPT-4.1 on GPQA-Diamond phi 0.81-0.93; on AIME phi 0.59-0.78 with a residual of 1.54-2.80 Gamma units; open-weights replication (Qwen3.5-9B/122B, Qwen3.8-27B, Gemma4-26B/31B, K=32 votes) phi about 1 in all ten cells (max 1.041). Conclusion: agreement is "graded evidence rather than certification"; no new voting method proposed — [Wrong-Consensus Decomposition](https://arxiv.org/abs/2608.18795)
- Conformal Social Choice: 586 final-round wrong-consensus cases on MMLU-Pro, 81.9% non-singleton at alpha=0.05 (90.8% LogiQA, 87.3% GPQA), over-rejection of correct consensus 31.9%; consensus stopping "never escalates but commits to high error rates" — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Budgeted Act-or-Defer: consensus stopping on GPQA acts on 87.0% of items at 71.3% accuracy; the kNN bound acts on 53.3% at 82.5%; on MuSR it activates on only 2 of 10 splits, which the authors call intended deferral under insufficient calibration evidence — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- R²-MAD defines the shared-misconception subset as questions where a majority of MAD agents are wrong at round 0 (count not reported). Correct-to-wrong / wrong-to-correct rates with vs without confidence weighting, Qwen3-8B Economics 0.077 / 0.049 vs 0.333 / 0.033; Gemma-3-4B Economics 0.196 / 0.098 vs 0.385 / 0.077; but Qwen3-8B TruthfulQA 0.294 / 0.079 vs 0.222 / 0.133 (weighting worse). On this subset all methods score below 10% on Economics (Figure 4) — [R²-MAD appendices](https://arxiv.org/html/2609.03619)
- VeriHarness: the consensus challenger tests claims shared by all rollouts and looks for requirements every rollout omitted, because "unanimity can hold even when every candidate is incorrect" — [VeriHarness](https://arxiv.org/html/2610.00972)
- ECMR: false-consensus rate 40.7% to 17.0% on MedQA/CaseHOLD/FinQA by routing to verify or arbitrate when support is narrow, duplicated or correlated — [ECMR](https://arxiv.org/abs/2610.17869)
- Okawa (ICML 2026, accepted): mean-field Ising/Potts model, m(t+1) = tanh[beta(J m(t) + h)], critical point beta J = 1; biased consensus emerges once lambda z-bar / T >~ 1 (conformity times effective neighbours over sampling temperature). Low noise (T < 0.5) induces early biased consensus; shifts of about delta T = 0.1 can flip the outcome. Mixing GPT-4.1, Llama 405B and DeepSeek at T=1.2: homogeneous populations reach m(R) in [-0.7, 0.5], mixed populations [-0.5, 0.2]. Real-world mitigation is temperature heterogeneity (investment N=6 at T in {1.4,1.5,1.6}; LLM-as-judge N=10 at T in {1.3-1.7}), which lowers bias norm (Fig. 7, numbers not in text). Sycophancy prompting (higher lambda) worsens emergence. Eleven LLMs across five families. Limitations: simplified protocol, discretised outputs, two synthetic and two realistic tasks — [Okawa full text](https://arxiv.org/html/2608.02827)
- Heterogeneous Debate Under Adversarial Peers (preprint v1 18 Jun 2026): Llama-3.1-70B defenders on MATH-hard, harmful-revision rate in honest slots 89% in a homogeneous panel, 35% with an honest heterogeneous peer, back to 90% with an adversarial heterogeneous peer; with a same-family adversary present, adding an honest heterogeneous peer cuts flips on initially correct items from 31% to 6%. Four families, three benchmarks; only Llama and MATH-hard named on the abstract page — [Adversarial Heterogeneity](https://arxiv.org/abs/2606.19826)
- Are Diversity Metrics Measuring Diversity? (Kim, preprint v1 22 Jul 2026): 31,900 subsets of 30 LLMs on MMLU-Pro (29 on TruthfulQA); oracle gain positive in 100% of subsets but simple voting beats the strongest member in only 9.98% of size-3 subsets (18.71% with held-out best selection; 1.27% pooled sizes 2-4); the joint-correctness diversity measure correlates with (1 - mean accuracy) at Spearman +0.991; after capability control the one stable signal is that more shared errors go with lower voting gain — [Diversity Audit](https://arxiv.org/abs/2607.20768)
- Consensus Trap (Liu, Du, Du, Guo, Conitzer; preprint v1 18 Apr 2026): response-level majority voting "collapses" once prompt-injected agents form a local majority because it sees only final conclusions; token-level round-robin generation in a shared context keeps accuracy past that threshold; no numbers on the abstract page — [Consensus Trap](https://arxiv.org/abs/2604.17139)
- Wynn et al.: in the diverse one-of-each configuration debate raised MMLU from 57.8 to 63.4 and GSM8K from 86.8 to 90.2 while every homogeneous or near-homogeneous configuration fell on MMLU; CSQA fell for all — [Wynn et al. full text](https://arxiv.org/html/2509.05396v2)
- SPLIT: Llama-3-8B and Gemma-7B per-problem solve rates correlate 0.80 on MATH; assuming independent failures overstates mixing gain by up to about 7 points; SPLIT predicts the real mixing gain with mean error 0.43 vs 2.81 under independence — [SPLIT](https://arxiv.org/html/2610.23255)

### Inferences
- Two families of answer exist. Calibration rules (Conformal, Act-or-Defer) cannot tell a shared misconception from a hard question; they notice that the pooled distribution is not sharp enough and defer, paying 31.9% over-rejection of correct consensus. Grounded verifiers (VeriHarness, ECMR's verify action, SPLIT with real tests) can in principle test the shared claim, and VeriHarness is the only one whose design names this case explicitly.
- Heterogeneity is a dampener with a measured mechanism (Okawa: averaging nonlinear response curves smooths the transition) and a measured attack surface (adversarial heterogeneous peer restores the 90% harmful-revision rate). The diversity audit and SPLIT both show that cross-model error correlation (0.80 on MATH for two open 7-8B models) is high enough that model mixing alone buys far less than independence would predict.
- The wrong-consensus decomposition implies that for open-weights models nearly all agreement is explained by per-question answer preference (phi about 1), so agreement among samples of the same model carries almost no information about correctness beyond that preference.

### Gaps
- No paper reports the fraction of shared-misconception cases that a grounded verifier actually overturns (VeriHarness reports selection averages, not a wrong-consensus breakdown; R²-MAD's subset size is unreported).
- Okawa's Fig. 7 numbers for the temperature-heterogeneity intervention are not in the text.
- The Consensus Trap paper's thresholds and accuracy figures are not on the abstract page.

## Key question 5: What do the papers say remains open?

### Takeaway
The open items the papers themselves name are: labelled calibration or memory data from the deployment distribution (R²-MAD, Conformal, Act-or-Defer, SPLIT all assume it); transfer of reliability or memory across tasks (R²-MAD flags it, nobody tests it); the representation gap when a debate is compressed to a low-dimensional state (Act-or-Defer); open-ended generation beyond multiple choice (Conformal, Act-or-Defer, Hao, Consensus is Not Verification); separating harness gain from capability gap when the verifier is the generator (VeriHarness); and compute-matched selection above 32B, which no paper runs. The question the brief raised, whether the highest-stated-confidence agent wins when wrong, has still not been directly measured in a multi-agent setting; the nearest data are the single-judge CW-POR setup and Consensus is Not Verification's Highest-Confidence aggregator, which gave no gain.

### Cited Findings
- R²-MAD: "requires an outcome signal for past debates"; memory "built offline and fixed at test time" and "may degrade if deployment tasks differ substantially"; cross-task transfer flagged as a risk and left to future work; a mistaken memory bank "could reinforce an error" — [R²-MAD full text](https://arxiv.org/html/2609.03619)
- Conformal Social Choice: marginal not conditional coverage; adaptive stopping outside the guarantee; exchangeability breaks under shift ("calibrating on one exam year and testing on another"); verbalised probabilities "noisy and prompt-sensitive"; closed-set only; 12 calls per question — [Conformal Social Choice full text](https://arxiv.org/html/2604.07667)
- Budgeted Act-or-Defer: "geometry-sufficiency trade-off is named as the central open challenge"; future work on learned representations and open-ended generation; assumption violations "add directly to the wrong-action bound" — [Act-or-Defer full text](https://arxiv.org/html/2606.29654v1)
- SPLIT: "all estimators assume the pilot represents deployment conditions. Capability drift breaks them for small pilots"; long same-agent horizons untested "since no public release has enough rollouts per issue" — [SPLIT](https://arxiv.org/html/2610.23255)
- VeriHarness: "covers only same-model verification, so it does not separate harness gains from capability gaps"; no calibrated per-rollout scores — [VeriHarness](https://arxiv.org/html/2610.00972)
- Agent S3: needs independent rollouts from one initial state; live desktops and shared external state break this — [Agent S3 full text](https://arxiv.org/html/2510.02250v2)
- Hao et al.: homogeneous GPT-4o only; one round of exposure; "convergence is an ambiguous signal of value", debate should be judged by "what peer information contributes to the final group answer" — [Hao et al. full text](https://arxiv.org/html/2606.00820v2)
- Consensus is Not Verification: "Polling is not a substitute for verification"; binary questions only; stronger diversity methods untested; agreement-as-risk-flag proposed but not tested — [Consensus is Not Verification full text](https://arxiv.org/html/2603.06612v1)
- Demystifying MAD: "assumes calibrated confidence correlates with correctness. Miscalibration could weaken it"; heterogeneous models future work; reward hacking observed (agents stopped engaging) — [Demystifying MAD](https://arxiv.org/html/2601.19921v3)
- Wynn et al. recommendations: reward critical evaluation over consensus; weight by confidence or credibility; reward independent verification; penalise unsupported conformity. Their own payoff-prompt experiment did not reduce harmful flips — [Wynn et al. full text](https://arxiv.org/html/2509.05396v2)
- Okawa: higher-stakes domains (legal, medical, educational) left to future work; protocol simplified — [Okawa full text](https://arxiv.org/html/2608.02827)
- Selection Bottleneck: weaker-model benefit exploratory, not pre-registered; single-round generate-then-select only — [Selection Bottleneck](https://arxiv.org/abs/2603.20324)
- Wald-SPRT: judge consensus score fails to separate useful from unhelpful convergence on MMLU (calibrated KL about 0), so the governor hit the cap on 99.5% of items; 40-item calibration sets — [Wald-SPRT](https://arxiv.org/abs/2605.19193)
- CW-POR (Agarwal & Khanna, preprint v1 1 Apr 2025): single-turn, one truthful agent vs one falsehood-defender on TruthfulQA, same-architecture judge, five open models 3B-14B, verbosity 30-300 words; even small models write arguments that override truthful answers "often with high confidence"; rates figure-only on the abstract page — [CW-POR](https://arxiv.org/abs/2504.00374)
- Consensus is Not Verification includes "Highest Confidence" as an aggregator (pick the single most confident sample) and reports no consistent gain over one sample; this is the closest measured proxy for "most confident wins", but it is over samples of one model, not over agents in a debate — [Consensus is Not Verification full text](https://arxiv.org/html/2603.06612v1)
- DASE: a verbalised-confidence router (Opus 4.6) and a commit-type router reach the same 25.5-25.7 pp accuracy gap at matched coverage yet disagree on 37% of routing assignments, so the two signals are not measuring the same thing — [DASE](https://arxiv.org/abs/2605.04236)

### Inferences
- On the brief's four open questions: (1) highest-stated-confidence agent winning when wrong: not measured in a multi-agent aggregation; nearest proxies are CW-POR (judge overridden, single turn, 3-14B) and the Highest-Confidence aggregator in Consensus is Not Verification (no gain over one sample). (2) Reliability weights transferring across tasks: R²-MAD is the only reliability-weighting paper and it names transfer as untested. (3) Calibration sets in deployment: all three calibration papers split the benchmark 50/50 and none tests calibrating on one source and deploying on another; Conformal and SPLIT both name shift as the failure mode. (4) Cost of selection vs debate at matched compute above 32B: Tran & Kiela (70B, Gemini 2.5 Pro) is the only matched run and it shows Ensemble-with-judge equal to Debate at 10k tokens (0.420 both) and both at or below a single agent; no grounded-verifier arm exists at that scale.
- The field's own stated direction is consistent: verification where a verifier exists (code, math, GUI state), calibrated deferral where it does not, and no further rounds of talk.

### Gaps
- No direct measurement, in any 2025-2026 paper found, of how often the agent with the highest stated confidence is wrong and wins a confidence-weighted vote.
- No test of reliability weights or memory banks estimated on one task and applied to another.
- No test of a conformal or kNN calibration set drawn from a different distribution than the test set.
- No compute-matched comparison of grounded best-of-N against a single agent given the same budget above 32B.
- Roundtable Policy's full results, the Consensus Trap's numbers, AgentAuditor's models, and Okawa's Fig. 7 values were not recoverable from the pages fetched.
