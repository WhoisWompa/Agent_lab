# Mind the Sim2Real Gap in User Simulation for Agentic Tasks

## One line
Runs the tau-bench protocol with 451 real people and 31 LLM user simulators and defines a User-Sim Index of simulator realism.

## Method


## Evaluated on
165 tasks; simulators are over-cooperative and stylistically uniform, an 'easy mode' that inflates agent success above the human baseline; simulated users give more positive feedback; more capable models are not more faithful simulators.
