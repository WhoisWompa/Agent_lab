# Agentic Rubrics as Contextual Verifiers for SWE Agents

## One line
An agent explores the repository to write a codebase-grounded checklist rubric, then scores candidate patches without running tests; 54.2% (Qwen3-Coder-30B-A3B) and 40.6% (Qwen3-32B) on SWE-Bench Verified best-of-N, >=3.5 pts over best baseline.
