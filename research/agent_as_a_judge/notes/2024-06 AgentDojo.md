# AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

## One line
Extensible environment of 97 user tasks and 629 security test cases where tool outputs carry injections; scored on utility and attack success by checking environment state.

## Method
Deterministic state checks for both the user task and the attacker goal; attacks and defenses pluggable.
