# Counsel: A Meta-Evaluation Dataset for Agentic Tasks

## One line
Human labels on process-level critiques by open-weight LLM judges over tau-bench and DA-Code trajectories.

## Method
Each flagged error labelled 'spot on', 'correct location but poor reasoning', or 'should not have flagged'.

## Evaluated on
Krippendorff alpha 0.78; strongest judge ~88% on error location, ~65% on reasoning; stronger judges and more reasoning effort improve agreement.
