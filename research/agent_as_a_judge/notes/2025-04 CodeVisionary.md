# CodeVisionary: An Agent-based Framework for Evaluating Large Language Models in Code Generation

## One line
Two-stage agent evaluator for code (requirement-guided multi-dimensional context distillation, then fine-grained scoring and report); 363-sample benchmark, 37 scenarios, 23 languages; +0.217 Pearson, +0.163 Spearman, +0.141 Kendall over best baseline.
