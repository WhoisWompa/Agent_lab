# LAVOIR: Teaching a Single-Pass Decision Encoder When and What to Ask with Amortized Value of Information

## One line
Extends the open "System One" decision encoder Laya so that one forward pass returns both the decision distribution and, for each missing piece of information, how much asking about it would raise the probability of the correct answer, which lets the model decide whether to ask a clarifying question, decide, or hand off.

## Method
Problem: single-pass decision models (Jev, Laya) must decide from whatever text they get, and real first messages are underspecified. They can only guess or escalate, so in the paper's opening example Laya's confidence is 0.12, it hands off, and its best guess is wrong anyway.

Idea: list the candidate missing facts ("slots") in the input as a second block of [MASK] markers next to the answer options. A small VOI head reads each slot marker plus summary features of the decision distribution and predicts the value of information: the expected gain in probability of the correct unit if that slot were asked. The policy asks the highest-value slot if its value beats a question cost c, re-encodes with the answer, and otherwise decides, or hands off if still uncertain. Question wording is a fixed template per slot; the model only chooses which slot. A zero-initialised segment embedding means that with no slots the model reproduces Laya's logits bit for bit.

Why it can learn without human labels: gold decisions come from hand-written schema rules over complete user profiles, so the exact Bayes posterior is computable by enumeration. Each message is paired with two to four profiles that differ in hidden values, so regressing on the realised gain p_k(gold) - p_0(gold) estimates the expected gain (an amortised VOI) rather than a deterministic mapping. The target uses the gold unit, not the model's own confidence, because a confidence-drop target would reward any answer that makes the model sure, including a misleading one. An LLM only writes the text; a model from another family rejects texts that leak hidden slots or omit stated ones.

The Gini cap: the true VOI can never exceed the Gini impurity 1 - sum p^2 of the posterior (an expected probability is at most 1). LAVOIR multiplies the head's sigmoid output by the detached Gini impurity of its own distribution, so a confident model structurally predicts a small value. This assumes the model is calibrated; if confidence is wrong, the cap silences questions exactly where they were needed.

## Evaluated on
- Decisions on seen schemas match the Bayes ceiling: accuracy 0.652 vs ceiling 0.659, gap -0.006 with a 95% interval containing zero, so the model neither under-uses the text nor exploits leaked hints.
- The question policy matches a greedy oracle VOI policy on seen schemas: AUC 0.799 vs 0.797 for the final model; with at most 0.5 questions per conversation, 0.751 accuracy vs 0.610 never asking and 0.663 asking at random.
- Choosing whether to ask from the VOI itself beats a prediction-set trigger using the same ranking: AUC 0.008-0.009 higher than baseline B5.
- The Gini cap makes questions targeted on real data: on SGD the asking rate falls from 93% to 8.6% at c=0.02; on ABCD one real exchange raises accuracy by +8.3 points [4.9, 11.7] where LAVOIR asks and -0.3 [-1.5, 1.0] where it does not, whereas the uncapped model gained +2.7 in both groups.
- Without the cap, the head ignores the bound out of distribution: among SGD cases with confidence at least 0.99 the median predicted VOI was 0.133, though the bound allows about 0.02.
- Laya's policy-gradient term is unnecessary: with it removed, decision accuracy is the same (0.918 vs 0.919) and VOI top-1 agreement improves (0.92 vs 0.88 seen, 0.75 vs 0.56 zero-shot).

## Limitations admitted by the authors
- Synthetic dialogues: answers come from a simulator whose answer types and rates the authors chose, and LLM-written users may be more cooperative than real ones; the real-data tests cover single exchanges, never the full asking loop with people.
- Zero-shot schemas stay far below the ceiling: 0.51-0.52 accuracy against 0.667, so the model does not learn to read unseen rules from option descriptions after training on eight schemas.
- Out-of-distribution calibration is weak (ABCD ECE 0.19), and on ABCD the model is wrong in 19% of cases where its confidence is at least 0.99. There the cap correctly suppresses questions given the stated confidence, but the confidence is wrong.
- Missing baselines: no slow VOI that re-encodes every possible answer, no LLM agent, no ablation of the self-referential target, so the claim that the gold-based target is better is argued, not shown.
- One seed, English only, questions are slot templates, and Laya's numbers are taken from its repository with a different training mixture, so the "above Laya on seven of twelve benchmarks" comparison is not controlled.
- Residual slot overlap in the privacy schema caused 22% message rejection, a mild selection effect on that schema.

## What it leaves untried
- Generating or discovering slots: every slot and its value set is hand-written in a schema, so the method only works where someone has already enumerated what could be missing; deploying on open-ended judging or routing would need slots proposed automatically.
- Fixing calibration before relying on the cap: the cap's silence is only as good as the model's confidence (19% wrong at 0.99 on ABCD), yet no recalibration on real dialogues is tried; the authors name the ABCD training split as a next step but do not run it.
- Non-greedy, multi-question planning: both LAVOIR and its oracle look one question ahead, so the paper never tests whether planning pairs of questions (as in its own two-question example) would beat greedy asking.
