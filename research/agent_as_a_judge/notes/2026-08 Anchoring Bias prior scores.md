# Anchoring Bias in LLM-as-a-Judge Systems: Prior Scores Compromise Evaluation Independence

## One line
Prior scores in context metadata anchor judgments (Cohen's d up to 0.71, 7/8 models); on labelled industry data anchoring blocks 48% of error corrections; neither CoT nor a 'disregard metadata' warning removes it.
