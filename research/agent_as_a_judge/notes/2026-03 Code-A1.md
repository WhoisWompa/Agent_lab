# Code-A1: Adversarial Evolving of Code LLM and Test LLM via Reinforcement Learning

## One line
Two separate models trained adversarially - a Code LLM rewarded for passing tests and a Test LLM rewarded for exposing defects - with a shared Mistake Book for replay.

## Method
White-box test generation: the Test LLM inspects candidate code to write targeted tests. A composite tester reward balances test validity against adversarial difficulty. The Mistake Book stores past failures for experience replay to stabilise co-evolution.

## Evaluated on
On Qwen2.5-Coder models: code generation matching or exceeding training on human-annotated tests, and substantially better test generation (numbers in paper).

## Limitations admitted by the authors
- Names self-collusion (one model writing easy tests for itself) as the failure mode of single-model self-play; addressed by role separation.
