# Topic - communication topology and channels

How the shape and size of the communication structure among LLM agents (chain, tree, star, mesh, layered, random, agent count) and what passes over an edge (text, summaries, artifacts only, embeddings or hidden states, protocol envelopes) determine task quality, cost and context load, including scaling in the number of agents. The subject is the structure and the channel, not the roles in it and not a search for it.
