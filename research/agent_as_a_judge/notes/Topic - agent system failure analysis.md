# Topic - agent system failure analysis

Empirical studies of how LLM agents and multi-agent systems fail in operation or in traces: failure taxonomies built from incidents or runs, silent and plausible-looking failures, how failures are discovered, and the defences that follow. The subject is the failure record and what it implies for building the system, not a benchmark score or a judge's accuracy.
