# Laminar (lmnr): open-source agent tracing and evals

## One line
Laminar is an Apache-2.0, self-hostable agent observability platform (3.4k stars) for tracing multi-step agents, playgrounds and evaluation datasets.

## What they do
Tracing with execution visualisation for multi-step/browser agents, prompt playground, eval datasets for regression testing; Docker Compose/Helm self-host (https://www.toolmage.com/de/tool/laminar/ — low-quality aggregator).
